# Atividades de C, MySQL e Git

Este repositório foi criado para organizar e compartilhar minhas atividades e meus estudos do primeiro período do curso de **Análise e Desenvolvimento de Sistemas (ADS) no SENAC Pernambuco**.

Aqui, desenvolvo exercícios e pratico conceitos de programação em **C**, banco de dados com **MySQL** e controle de versão com **Git**.

O **Git** é uma ferramenta que permite acompanhar as alterações feitas nos arquivos ao longo do tempo, facilitando a organização dos estudos, o registro da evolução do código e o gerenciamento de diferentes versões dos projetos.

Este repositório faz parte da minha jornada de aprendizado na programação. Como estudante iniciante, meu objetivo é praticar, aprender com meus erros e acompanhar minha evolução ao longo do curso.
